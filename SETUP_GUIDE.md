# LookCheck AI — подробная инструкция по запуску (для новичка)

Этот проект состоит из **двух частей**, которые нужно запустить по очереди:

1. **lookcheck-backend** — Python-сервер, который делает всю "умную" работу (AI, погода, база данных)
2. **lookcheck-app** — мобильное приложение (React Native/Expo), которое ты будешь смотреть на телефоне

Инструкция написана максимально подробно — шаг за шагом, ничего не пропускаем.

---

## ЧАСТЬ 1: Запуск сервера (backend)

### Шаг 1.1 — Установи Python

Если Python ещё не установлен:
- **Windows/Mac:** зайди на https://www.python.org/downloads/, скачай и установи (версия 3.10 или новее)
- Важно на Windows: во время установки поставь галочку **"Add Python to PATH"**

Проверь, что всё установилось — открой терминал (на Windows это **Command Prompt** или **PowerShell**, на Mac — **Terminal**) и введи:
```
python3 --version
```
Должна показаться версия, например `Python 3.11.5`.

### Шаг 1.2 — Распакуй проект и перейди в папку backend

Распакуй присланный zip-архив, найди папку `lookcheck-backend`, и перейди в неё через терминал:
```
cd путь/к/папке/lookcheck-backend
```
(на Windows можно просто скопировать путь из адресной строки проводника)

### Шаг 1.3 — Установи зависимости

```
pip install -r requirements.txt
```

Если команда `pip` не находится — попробуй `pip3` вместо `pip`.

### Шаг 1.4 — Настрой файл с ключами (необязательно для первого запуска)

Скопируй файл `.env.example` и назови копию `.env`:
- **Windows:** через проводник — скопируй файл, переименуй копию
- **Mac/Linux:** в терминале `cp .env.example .env`

**Приложение прекрасно работает и без ключей** (в демо-режиме — покажет "заглушки" вместо реального AI/погоды), так что этот шаг можно пропустить и вернуться к нему позже.

Если хочешь реальный AI и реальную погоду сразу:
- **ANTHROPIC_API_KEY** — получи на https://console.anthropic.com/ (нужна регистрация)
- **OPENWEATHER_API_KEY** — получи бесплатно на https://openweathermap.org/api (регистрация, раздел API keys)

Впиши их в файл `.env` после знака `=`, например:
```
ANTHROPIC_API_KEY=sk-ant-...твой ключ...
OPENWEATHER_API_KEY=...твой ключ...
```

### Шаг 1.5 — Запусти сервер

```
python3 app.py
```

Если всё хорошо, увидишь что-то вроде:
```
* Running on http://127.0.0.1:8000
```

**Не закрывай это окно терминала** — сервер должен продолжать работать, пока ты пользуешься приложением. Если закроешь окно — сервер остановится.

### Шаг 1.6 — Узнай IP-адрес своего компьютера

Это важно для шага 2 (мобильное приложение). Открой **новое** окно терминала (первое не трогай — там работает сервер!) и введи:

- **Windows:** `ipconfig` → найди строку **"IPv4 Address"**, например `192.168.1.42`
- **Mac:** `ifconfig | grep "inet "` → найди адрес, начинающийся на `192.168.` или `10.`
- **Linux:** `ip a` → аналогично

Запиши этот адрес — он понадобится в следующей части.

## ЧАСТЬ 2: Запуск мобильного приложения

### Шаг 2.1 — Установи Node.js

Зайди на https://nodejs.org/, скачай и установи версию **LTS** (рекомендованную).

Проверь установку:
```
node --version
npm --version
```

### Шаг 2.2 — Установи приложение Expo Go на телефон

- **Android:** найди "Expo Go" в Google Play
- **iPhone:** найди "Expo Go" в App Store

Это приложение позволит запустить твоё приложение на телефоне без публикации в сторы — просто отсканировав QR-код.

### Шаг 2.3 — Создай чистый Expo-проект

Это самый надёжный способ (чтобы не было конфликтов версий). В терминале:

```
npx create-expo-app@latest lookcheck-app-run
cd lookcheck-app-run
```

Подожди, пока всё установится (может занять пару минут).

### Шаг 2.4 — Установи нужные библиотеки

```
npx expo install @react-navigation/native @react-navigation/bottom-tabs @react-navigation/native-stack react-native-screens react-native-safe-area-context expo-image-picker expo-location @react-native-async-storage/async-storage
```

Дождись завершения установки.

### Шаг 2.5 — Скопируй файлы проекта

Из присланного архива, из папки `lookcheck-app`, скопируй в свой новый проект (`lookcheck-app-run`):

1. Файл `App.js` — **замени** им существующий `App.js` в новом проекте
2. Всю папку `src/` — скопируй целиком внутрь `lookcheck-app-run`
3. Файл `app.json` — **замени** им существующий `app.json`

После копирования структура должна выглядеть так:
```
lookcheck-app-run/
├── App.js          (заменённый)
├── app.json         (заменённый)
├── src/              (новая папка, скопирована целиком)
│   ├── api/
│   ├── context/
│   ├── screens/
│   └── components/
├── package.json      (не трогаем, он уже настроен шагом 2.4)
└── ...остальные файлы, которые создал create-expo-app
```

### Шаг 2.6 — Укажи адрес сервера

Открой файл `src/api/client.js` в любом текстовом редакторе (например, VS Code, Notepad).

Найди строку:
```javascript
export const API_BASE_URL = 'http://192.168.1.42:8000'; // <-- CHANGE THIS
```

Замени `192.168.1.42` на **свой** IP-адрес, который ты узнал в Шаге 1.6. Порт `:8000` оставь как есть.

**Важно:** телефон и компьютер должны быть в одной Wi-Fi сети!

### Шаг 2.7 — Запусти приложение

В терминале, находясь в папке `lookcheck-app-run`:
```
npx expo start
```

Появится QR-код прямо в терминале (и в открывшемся окне браузера).

### Шаг 2.8 — Открой на телефоне

- **Android:** открой приложение Expo Go → "Scan QR code" → наведи камеру на QR-код в терминале
- **iPhone:** открой обычную камеру телефона → наведи на QR-код → нажми на всплывающее уведомление (откроется в Expo Go)

Приложение соберётся и откроется на телефоне (первая сборка может занять минуту-две).

## Если что-то не работает

**"Network request failed" при использовании приложения**
→ Проверь: сервер (Часть 1) точно ещё запущен? IP-адрес в `client.js` совпадает с тем, что показал `ipconfig`/`ifconfig`? Телефон и компьютер в одной Wi-Fi сети (не мобильный интернет на телефоне)?

**Не открывается QR-код / телефон не подключается**
→ Иногда помогает командой `npx expo start --tunnel` вместо обычного `npx expo start` — это создаёт туннель через интернет, работает даже если Wi-Fi настроен со странными ограничениями (но чуть медленнее).

**Ошибка при `npm install` / `npx expo install`**
→ Проверь подключение к интернету. Попробуй удалить папку `node_modules` и файл `package-lock.json`, затем повторить команду.

**Сервер (Часть 1) не отвечает / "Address already in use"**
→ Значит, порт 8000 уже занят. Останови старый процесс сервера (Ctrl+C в его окне терминала) и запусти заново.

## Что работает без API-ключей, а что нет

| Функция | Без ключей | С ключами |
|---|---|---|
| Создание профиля, гардероб (ручной ввод) | ✅ Полностью работает | ✅ |
| Погода | ⚠️ Показывает фиктивную погоду (Demo City, +15°C) | ✅ Реальная погода |
| Анализ фото/ссылки при добавлении вещи | ⚠️ Заглушка ("White T-shirt, demo mode") | ✅ Реальный AI-анализ |
| Подбор образа на день/событие | ⚠️ Просто берёт первые вещи из гардероба | ✅ Реальный AI-подбор с объяснением |

Так что можно сразу всё пощупать без единого API-ключа, а потом при желании включить "настоящий" AI и погоду.
